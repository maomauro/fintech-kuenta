# Kuenta · Arquitectura

**Kuenta** es una fintech colombiana **ficticia** de ahorros, pagos y créditos. Este sitio documenta, paso a paso, la arquitectura que diseña un arquitecto de software recién contratado: desde el caso de negocio hasta el despliegue en **AWS** (Amazon Web Services).

## Cómo navegar

- **Módulos**: una nota por módulo, con lo hecho y lo decidido.
- **Requisitos**: catálogo de requisitos, historias de usuario y casos de uso.
- **Decisiones (ADR)**: cada decisión de arquitectura en un registro (*Architecture Decision Record*).

## Estado

El proyecto avanza módulo a módulo. Hoy está en el **Módulo 0: entorno y herramientas**.
