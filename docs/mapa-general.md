# Mapa general

Cómo se implementa una arquitectura, de principio a fin, con Kuenta como ejemplo. Son ocho pasos; cada uno responde una pregunta y deja un entregable. Elige un paso para ver su detalle.

<MapaGeneral />

:::note Alcance
Es una síntesis propia del curso, apoyada en métodos como TOGAF, pensada para construir algo nuevo. Si la iniciativa es modernizar un sistema existente, se añade al inicio un paso para levantar la arquitectura actual. El detalle de los pasos 5 a 8 es lo que se prevé hacer y se confirma al llegar a cada módulo.
:::
