# Entrevista

El guion y el banco de preguntas viven en el sitio, dentro de `docs/publicacion-y-exposicion/`:

- Guion de entrevista: presentación de 2 minutos, recorrido de 10 minutos y cifras clave.
- Banco de preguntas: una pregunta típica por módulo, con respuesta modelo y enlace al detalle.

Se mantienen en `docs/` para que el sitio los publique y para que sus enlaces se validen en cada construcción.
