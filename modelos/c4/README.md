Copias editables en draw.io de las vistas C4 del Módulo 5. La fuente de verdad es `../structurizr/kuenta.dsl`: si el modelo cambia, hay que actualizar estos archivos a mano (o regenerarlos).

| Archivo | Nivel |
|---|---|
| `nivel-1-contexto.drawio` | 1 · Contexto |
| `nivel-2-contenedores.drawio` | 2 · Contenedores |
| `nivel-3-componentes.drawio` | 3 · Componentes (los 8 módulos) |
| `nivel-4-codigo-clases.drawio` | 4 · Código (opcional): clases de Cuentas y depósitos, dibujado a mano (no sale de Structurizr) |

Abrir con draw.io (app de escritorio o diagrams.net). Para publicar en el sitio, exportar a SVG y guardar en `../../diagramas/`.
