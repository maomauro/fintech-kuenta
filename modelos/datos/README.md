# Modelos de datos y consistencia (draw.io)

Copias editables en draw.io de los diagramas del Módulo 6. Se abren en [app.diagrams.net](https://app.diagrams.net) o en la aplicación de escritorio.

La fuente de verdad son las páginas de `docs/datos-y-consistencia/`, donde los diagramas están escritos en Mermaid. Estas copias existen para ampliarlos, retocarlos y exponerlos.

| Archivo | Contenido | Página del sitio |
|---|---|---|
| `er-general.drawio` | Modelo de datos general, agrupado por módulo dueño | Modelo de datos |
| `libro-mayor.drawio` | Detalle del libro mayor: depósito, cuenta del libro, operación, apunte y reserva | Libro mayor |
| `flujo-eventos.drawio` | Publicadores, outbox, despachador y consumidores | Flujo de eventos |
| `saga-breb-estados.drawio` | Estados de una transferencia por Bre-B | Sagas y estados |
| `saga-breb-secuencia.drawio` | Secuencia con respuesta pendiente | Sagas y estados |
| `estados-efectivo.drawio` | Estados de depósito y retiro de efectivo | Sagas y estados |

Si se cambia un diagrama, se actualiza primero la página del sitio y después su copia, para que no se desalineen.
