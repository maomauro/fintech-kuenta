# Mapa de integraciones (Módulo 7)

`mapa-integraciones.drawio` es una copia editable en draw.io del diagrama de la página [Mapa de integraciones](../../docs/integracion-y-apis/mapa-de-integraciones.md).

La fuente de verdad es el diagrama Mermaid de esa página; si cambia, esta copia debe actualizarse a mano.
